# Instagram UI Clone (HTML & CSS)

A static front-end clone of the Instagram web interface built strictly with **HTML5** and **CSS3**. This project focuses on replicating the core visual layout, spacing, and responsive design of Instagram without JavaScript or a backend.

## Features
- **Sidebar / Navigation Bar:** Clean navigation menu with icons and hover states.
- **Stories Section:** Horizontal story bar with styled profile rings.
- **Feed Layout:** Post cards featuring user headers, media placeholders, action icons, and caption formatting.
- **Suggestions Sidebar:** Right-hand profile summary and suggested accounts section.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screen sizes.

## Tech Stack
- **HTML5** (Semantic markup)
- **CSS3** (Flexbox, CSS Grid, custom variables, media queries)
